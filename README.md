# Data Analytics Portfolio

See repository koondab minu 11-nädalase intensiivse **DACA (Data Analyst Career Accelerator)** 6. lenda simulatsiooniprogrammi raames tehtud praktilised projektid ja andmebaasi analüüsid.

---

## 🏢 Ärikontekst: UrbanStyle

Kõik selles portfoolios olevad projektid lahendavad Eesti jätkusuutliku moeettevõtte **UrbanStyle.ltd** reaalseid andmeprobleeme:
* **Eesmärk:** Korrastada killustunud andmesüsteemid ning luua tegevjuhile ja IT-direktorile andmepõhine äriplaan investorite pitchiks.
* **Iganädalane protsess:** Analüüsida andmestikku ja presenteerida vahetulemusi iganädalaselt vastavale osapoolele (*stakeholder*), kohandades esitluse vormi ja fookust vastavalt kuulaja rollile.
* **Andmestik:** Müügiandmed (`sales`), klientide info (`customers`), tootekataloog (`products`), varud (`inventory`) ja veebilogid (`web_logs`).

---

## 🛠️ Kasutatud tööriistad ja tehnoloogiad

* **Andmebaasid & SQL:** PostgreSQL, Supabase
* **Andmetöötlus & Python:** Python 3, pandas, NumPy
* **Visualiseerimine & Dashboardid:** Power BI / Plotly & Streamlit
* **Arenduskeskkond & Versioonihaldus:** VS Code, Git, GitHub
* **Dokumentatsioon:** Markdown, Miro
